# Fork Notes

This fork exists to develop and test a **generic CLI-based text-to-speech (TTS) provider
framework** for OpenClaw (April 2026).

The feature space has since evolved: OpenClaw 2026.4.27 ships `tts-local-cli` natively,
covering the local-CLI TTS use case this work explored. The fork's history is kept as a
reference for that approach.

## Using this fork

- `main` tracks upstream `openclaw/openclaw`.
- The TTS provider work lives in this fork's history for reference.
